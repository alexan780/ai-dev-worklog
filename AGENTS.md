# Repository Instructions

This is an independent open-source project.

## Project Scope

- v0.1 focuses only on the local TypeScript CLI core.
- The v0.1 CLI scans local git evidence and writes local worklog output files.
- Local git evidence is the source of truth for observed code changes.
- Keep dependencies minimal and justified.
- Describe current capabilities precisely.

## v0.1 Boundaries

Do not implement these features in v0.1:

- Codex App integration
- Claude Code integration
- Cursor integration
- MCP tools
- AI API calls
- chat window reading

## Public Repository Hygiene

- Keep this repository independent from private projects, private asset libraries, private business work, private local paths, and user-specific internal workflows.
- Avoid references that make the project look tied to a private product or local personal setup.
- Keep documentation focused on what this open-source CLI does today and what is clearly marked as future work.
